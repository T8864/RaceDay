# RaceDay - Race Event Management System

## System Description
RaceDay is a web-based race event management system that allows Organisers to create and manage race events, and Participants to enrol in those events. The system manages events, categories, enrolments and results.

## Roles

### Organiser
- Create, update and delete race events
- Manage race categories
- View all participants and enrolments
- Add race results

### Participant
- Register and log in to the system
- View available events and categories
- Enrol in events
- View their own results

## Database
The system uses SQL Server with the following entities:
- Organisers
- Participants
- Events
- Categories
- Enrolments
- Results
