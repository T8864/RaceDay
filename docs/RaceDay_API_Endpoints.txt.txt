RACEDAY API ENDPOINT PLAN
==========================

1. AUTH ENDPOINTS
-----------------

Method: POST
Route: /api/auth/register
Description: Register a new user as either an Organiser or Participant
Role Required: Public
Request Body: { "firstName": "string", "lastName": "string", "email": "string", "password": "string", "role": "Organiser|Participant" }
Expected Response:
  201 - { "message": "User registered successfully", "userId": 1 }
  400 - { "message": "Validation error - all fields are required" }
  409 - { "message": "Email already exists" }

Method: POST
Route: /api/auth/login
Description: Login with email and password and receive a JWT token
Role Required: Public
Request Body: { "email": "string", "password": "string" }
Expected Response:
  200 - { "token": "jwt_token", "role": "Organiser|Participant" }
  401 - { "message": "Invalid email or password" }
  400 - { "message": "Email and password are required" }

2. ORGANISER ENDPOINTS
-----------------------

Method: GET
Route: /api/organisers
Description: Get a list of all organisers in the system
Role Required: Organiser
Request Body: None
Expected Response:
  200 - [ { "organiserID": 1, "firstName": "John", "organisationName": "Cape Town Running Club" } ]
  401 - { "message": "Unauthorised - login required" }
  403 - { "message": "Forbidden - Organiser role required" }

Method: GET
Route: /api/organisers/:id
Description: Get a single organiser by their ID
Role Required: Organiser
Request Body: None
Expected Response:
  200 - { "organiserID": 1, "firstName": "John", "email": "john@raceday.com", "organisationName": "Cape Town Running Club" }
  404 - { "message": "Organiser not found" }
  401 - { "message": "Unauthorised - login required" }

Method: PUT
Route: /api/organisers/:id
Description: Update an organiser's details
Role Required: Organiser
Request Body: { "firstName": "string", "lastName": "string", "phone": "string", "organisationName": "string" }
Expected Response:
  200 - { "message": "Organiser updated successfully" }
  400 - { "message": "Validation error - invalid fields" }
  404 - { "message": "Organiser not found" }
  403 - { "message": "Forbidden - you can only update your own profile" }
