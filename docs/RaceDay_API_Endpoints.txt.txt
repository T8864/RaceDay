RACEDAY API ENDPOINT PLAN
==========================

1. AUTH ENDPOINTS
-----------------
Method: POST
Route: /api/auth/register
Description: Register a new user (Organiser or Participant)
Role Required: Public
Request Body: { "firstName": "string", "lastName": "string", "email": "string", "password": "string", "role": "Organiser|Participant" }
Expected Response: 201 - { "message": "User registered successfully", "userId": 1 }

Method: POST
Route: /api/auth/login
Description: Login and receive a token
Role Required: Public
Request Body: { "email": "string", "password": "string" }
Expected Response: 200 - { "token": "jwt_token", "role": "Organiser|Participant" }

2. ORGANISER ENDPOINTS
-----------------------
Method: GET
Route: /api/organisers
Description: Get all organisers
Role Required: Organiser
Request Body: None
Expected Response: 200 - [ { "organiserID": 1, "firstName": "John", "organisationName": "Cape Town Running Club" } ]

Method: GET
Route: /api/organisers/:id
Description: Get a single organiser by ID
Role Required: Organiser
Request Body: None
Expected Response: 200 - { "organiserID": 1, "firstName": "John", "email": "john@raceday.com" }

Method: PUT
Route: /api/organisers/:id
Description: Update organiser details
Role Required: Organiser
Request Body: { "firstName": "string", "lastName": "string", "phone": "string" }
Expected Response: 200 - { "message": "Organiser updated successfully" }

4. EVENT ENDPOINTS
-------------------
Method: GET
Route: /api/events
Description: Get all events
Role Required: Public
Request Body: None
Expected Response: 200 - [ { "eventID": 1, "eventName": "Cape Town Spring Race", "eventDate": "2026-10-15" } ]

Method: GET
Route: /api/events/:id
Description: Get a single event by ID
Role Required: Public
Request Body: None
Expected Response: 200 - { "eventID": 1, "eventName": "Cape Town Spring Race", "location": "Cape Town", "maxParticipants": 500 }

Method: POST
Route: /api/events
Description: Create a new event
Role Required: Organiser
Request Body: { "eventName": "string", "eventDate": "date", "location": "string", "maxParticipants": "int", "organiserID": "int" }
Expected Response: 201 - { "message": "Event created successfully", "eventID": 4 }

Method: PUT
Route: /api/events/:id
Description: Update an event
Role Required: Organiser
Request Body: { "eventName": "string", "eventDate": "date", "location": "string" }
Expected Response: 200 - { "message": "Event updated successfully" }

Method: DELETE
Route: /api/events/:id
Description: Delete an event
Role Required: Organiser
Request Body: None
Expected Response: 200 - { "message": "Event deleted successfully" }
